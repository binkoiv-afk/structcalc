# ТЗ v0.2 — Программа инженерных расчетов (рабочее название «StructCalc»)

Дата: 2026-10-14 · Статус: в работе. Отдельный продукт, не связан с KMD.

## 1. Цель
Одна программа для конструктора/проектировщика: расчет элементов и узлов на прочность, жесткость и устойчивость, подбор сечений, сбор нагрузок, динамика. Нормы по странам (старт: Украина и ЕС), интерфейс и отчеты на нескольких языках. Две поставки из одного кода: браузер и десктоп.

## 2. Принципы
- **Одно расчетное ядро** для веба и десктопа. Никаких «двух версий формул».
- **Нормы как плагины.** Ядро считает механику (усилия, напряжения, прогибы), а модуль норм задает коэффициенты, сочетания, проверки и ссылки на пункты. Новая страна = новый модуль, без переписывания ядра.
- **Прозрачность расчета.** Каждая проверка выдает формулу, подстановку, результат, коэффициент использования и ссылку на пункт норм. Это и есть отчет.
- **Верификация.** Каждый модуль покрыт контрольными примерами из норм, учебников и ваших реальных расчетов (например, узел навеса). Без прохождения примеров модуль не выпускается.
- **Единицы.** Внутри строго СИ (Н, мм, МПа), ввод и вывод в любых единицах (кН, тс, кгс/см² и т.д.).

## 3. Модули

### Этап 2 — узлы и соединения
Болтовые и сварные соединения, анкеры (химия/механика, бетонное основание), опорные плиты, фланцы, кронштейны (как в расчете навеса). Нормы: ДБН В.2.6-198, EN 1993-1-8, EN 1992-4.

### Этап 3 — стержневые системы (МКЭ)
2D/3D рамы и фермы: МКЭ-решатель, расчет по I и II порядку (P-Δ), расчетные длины из анализа устойчивости, автоподбор сечений всей системы. Импорт/экспорт DXF, IFC.

### Этап 4 — динамика и сейсмика
Собственные частоты и формы, модальный анализ, пульсационная составляющая ветра, вибрации перекрытий от людей и оборудования, удар.
**Сейсмика:** спектральный метод (ДБН В.1.1-12:2014, EN 1998-1), сейсмичность площадки по картам, категории грунтов, коэффициенты поведения (q / K1), сочетание форм SRSS/CQC, сейсмические нагрузки на этажи, проверка перекосов, крепления навесных элементов и оборудования.

### Этап 4а — теплофизика
Сопротивление теплопередаче ограждений R и U (ДБН В.2.6-31:2021, ДСТУ Б EN ISO 6946), сравнение с нормативом по температурной зоне, теплопроводные включения (ψ, χ; кронштейны НВФ — EN ISO 10211), влажностный режим и точка росы (метод Глазера, EN ISO 13788), температура внутренней поверхности, теплоустойчивость, база материалов с λ.

### Этап 5 — другие материалы
Железобетон (ДБН В.2.6-98, EN 1992), дерево (ДБН В.2.6-161, EN 1995), алюминий (EN 1999; актуально для ламелей/фасадов), кладка (EN 1996), основания и фундаменты (ДБН В.2.1-10, EN 1997).

### Этап 6 — машиностроение (по желанию)
Валы, оси, пружины, резьбовые соединения, сварка на усталость, контактные напряжения, допуски и посадки.

## 4. Архитектура
```
┌──────────── UI (React) ─────────────┐
│ формы ввода · схемы · эпюры · отчет │
└──────────────┬──────────────────────┘
               │ один API
┌──────────────▼──────────────────────┐
│ Расчетное ядро (TypeScript)         │
│  mechanics/  — балки, сечения, МКЭ  │
│  codes/ua/   — ДБН/ДСТУ              │
│  codes/eu/   — EN + нац. приложения  │
│  catalog/    — сортаменты, материалы│
│  units/      — единицы               │
│  report/     — дерево проверок → PDF │
└──────────────┬──────────────────────┘
       ┌───────┴────────┐
   Браузер (PWA,     Десктоп (Tauri:
   работает офлайн)  Windows/macOS/Linux)
```
- Тяжелые вычисления (МКЭ, динамика) — в Web Worker; при необходимости — модуль на Rust/WASM.
- Хранение проектов: файл проекта (JSON) локально; облако — позже, опционально.
- Национальные приложения EN: выбор страны (PL, DE, FR, …) меняет NDP-параметры.

## 5. Стек
- TypeScript (монорепо pnpm), React + Vite, Zustand
- Графика: SVG для схем/эпюр, Three.js для 3D рам (этап 3)
- Отчеты: HTML → PDF (рендер в браузере/Tauri), DOCX через docx.js
- i18n: i18next; языки ru / uk / en / pl / de / fr, добавление — файлом перевода
- Тесты: Vitest (контрольные примеры), Playwright (UI)
- Десктоп: Tauri 2 (малый размер, работает офлайн)
- CI: GitHub Actions — тесты, сборка веб и десктоп-инсталляторов

## 6. План работ
1. Репозиторий, каркас монорепо, единицы, сортамент, геометрия сечений.
2. Балка + проверки стали по ДБН и EN + подбор профиля.
3. Сбор нагрузок (снег, ветер) и сочетания.
4. Отчет PDF в вашем стиле, i18n на 6 языков.
5. Веб-деплой (PWA) и десктоп-сборка → первая рабочая версия.
6. Далее этапы 2–6 по приоритету, который вы зададите.

## 7. Важные замечания
- Тексты норм платные/охраняемые: в программу закладываются формулы и таблицы коэффициентов со ссылками на пункты, а не полный текст норм.
- Результаты программы требуют проверки инженером; в отчете будет соответствующая отметка.
