Зусилля кінця стрижня беруться з епюр (N — розтяг +, M_y — розтяг верху +) для всіх сполучень ULS. Використання вузла повертається в таблицю стиків; змінена база повертається у вузол збірки, і збірка перераховується.

## v17 — рёбра колони, продавлювання болтами, свої деталі, специфікація, поради

- Ребра колони навпроти полиць балки: стиск сприймають смуга стінки b_eff і два ребра, F_c ≤ (b_eff·t_wc + 2·b_s·t_s)·R_y. Тест: використання стінки з ребрами менше, ніж без них; примітка про стійкість стінки знімається.
- Продавлювання листа головкою / гайкою найнавантаженішого болта: EN 1993-1-8, табл. 3.4, B_p,Rd = 0.6·π·d_m·t·f_u/γ_M2, d_m ≈ 1.6·d; для ДБН — π·d_m·t·R_s (формули в ДБН немає, вказано в перевірці). Перевіряються торцева плита (фланець) і полиця колони.
- Свої деталі (пластина, ребро, профіль) з положенням і орієнтацією — на кресленні в трьох проєкціях і в специфікації; у перевірки міцності не входять.
- Специфікація: пластини (габарити, кількість, маса ρ = 7850 кг/м³), болти, свої профілі. Тест: маса торцевої плити = ρ·h_p·b_p·t_p; 8 болтів для типової торцевої плити.
- Поради: для кожної перевірки, що не проходить, — що змінити; де можливо — «Застосувати» змінює параметр на крок (діаметр або клас болтів, товщина плити, катет, ребра колони, товщина накладок, фасонки, ребра). Якщо обрана сталь не постачається потрібної товщини, разом з товщиною пропонується сталь, що її має; за інших обставин — зрозуміле повідомлення замість NaN.

## v19 — вільний вузол: переріз деталі біля зв'язку, згин пластин між зв'язками

Пластини тепер не жорсткі тіла, а сітка оболонкових елементів (MITC4 + QM6, ~12 елементів на більший розмір, ≤ 200 на пластину); профілі лишаються жорсткими тілами. Точка шва кріпиться до пластини через білінійні функції елемента з жорстким відрізком від серединної площини до грані; болт — пружина між середніми переміщеннями кілець r = 0.8·d під головкою і гайкою (не точкове навантаження на оболонку). Сила на пластині — на латку вузлів (r ≥ 25 мм) з точними рівнодійною і моментом (RBE3). Система — профільний розклад Холецького з нумерацією RCM; нульовий ведучий елемент — механізм.

- Переріз деталі біля зв'язку: пластина на торці (шов по краю) — переріз уздовж шва на всі зусилля, σ = N/A + 6M_пл/(t·L²) + 6M_зпл/(L·t²), τ = 1.5·V/A + 3T/(L·t²); пластина з болтами або швом на грані — два перерізи нетто через центр групи (A_n = (L − n·d₀)·t) на дію в площині; профіль — переріз ⊥ осі: σ = N/A_n + M_y/W_y + M_z/W_z, τ = V/A_v + T/W_t. ДБН: σ ≤ R_y·γ_c і σ_ef ≤ 1.15·R_y·γ_c; EN: σ_eq ≤ f_y.
- Згин пластини між зв'язками: найбільші еквівалентні напруження на поверхнях у точках Гаусса, межа як вище. Карта σ_ef / межа по елементах з болтами й швами.

## v20 — контакт пластин, підважування, тертя

Для болтового зв'язку двох пластин, що лежать у площині зв'язку, на перекритті пластин ставиться сітка точок контакту (крок ≈ 12 мм, без отворів): пружина лише на стиск. Тертя: у стиснутих точках — зчеплення, поки |F_t| ≤ μ·F_c, далі ковзання із силою μ·F_c (ітерації з релаксацією, ≤ 40). μ = 0 за замовчуванням — зсув лише на болтах, як у нормах для звичайних болтів.
