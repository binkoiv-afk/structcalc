# Верификация расчетного ядра

Статус каждой нормативной величины. «Сверено» — совпадает с первоисточником или каталогом; «Требует сверки» — взято по памяти/вторичным источникам.

## Геометрия и сортамент
| Что | Статус | Чем проверено |
|---|---|---|
| A, I, W, Wpl, i для IPE/HEA/HEB | Сверено | каталог ArcelorMittal (IPE 200, 300; HEA 200; HEB 200), откл. < 1% |
| It, Iw двутавров | Сверено | IPE 300, HEB 200, откл. < 2% |
| Гнутые трубы EN 10219 | Сверено | 100×100×4: A, I, Wpl, It |
| ГОСТ 8239 | Приближенно | уклон полок не учтен, ~1% |
