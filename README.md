# StructCalc

Программа инженерных расчетов строительных конструкций: прочность, жесткость, устойчивость, подбор сечений, нагрузки, динамика, сейсмика, теплофизика. Нормы по странам (Украина ДБН/ДСТУ, Еврокоды), интерфейс на uk/ru/en/pl/de/fr. Одно ядро на TypeScript для веб- и десктоп-версии (Tauri).

ТЗ: [docs/TZ.md](docs/TZ.md)

## Структура
- `packages/core` — расчетное ядро: геометрия сечений, сортамент, МКЭ балки, проверки ДБН В.2.6-198 и EN 1993-1-1, подбор профиля
- `apps/web` — веб-интерфейс (React + Vite)

## Запуск
```
pnpm install
pnpm test        # контрольные примеры ядра
pnpm dev         # веб-интерфейс
```
